# Placement Skills Gap Analytics Dashboard

## Project Objective
Analyze student placement outcomes and industry technology demand
to identify technical skills associated with placement opportunities.

## Datasets
1. Student Placement Prediction Dataset — Kaggle
2. India Tech Career Intelligence [1M] — Mendeley Data

## Project Approach
Both datasets will be cleaned and analyzed independently.
Their findings will be compared to identify potential technical skill gaps.

## Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Git and GitHub

- Raw datasets are not included in this GitHub repository.
- Dataset source links and applicable license information are documented above.
