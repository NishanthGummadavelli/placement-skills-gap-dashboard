# Data Directory

This directory contains the datasets used in the Placement Skills Gap Analytics Dashboard project.

## Directory Structure

- `raw/` — Original datasets downloaded from their respective sources. These files are preserved without modification.
- `processed/` — Cleaned datasets generated by the data-cleaning scripts.

## Data Handling

- Original datasets are preserved to maintain data integrity.
- Data cleaning and preprocessing are performed using Python and Pandas.
- Cleaned datasets are stored separately in the `processed/` directory.
- Raw and processed dataset files are excluded from GitHub using `.gitignore`.
- Dataset sources and applicable licenses are documented in the main project README.

## Important Note

The cleaned datasets are used for exploratory data analysis and the Excel dashboard. The original datasets are not modified.
